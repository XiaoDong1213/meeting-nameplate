# 会议桌牌打印系统

> 面向会议、会务与桌签制作场景的 Windows 桌牌排版与打印软件。

会议桌牌打印系统是一款基于 **Python + PyQt6** 构建的 Windows 桌面应用。它将桌牌名单编辑、规格选择、抬头落款、单牌实时预览、排版预览与打印输出整合在一个工作流中。

软件采用 **主界面编辑 + 排版预览打印** 的模式：主界面用于填写名单与调整版式，预览窗口用于检查分页排版并发送到打印机或导出 PDF。

---

## ✨ 软件功能

### 📝 桌牌名单

- 每行一张桌牌，支持 Tab 分列。
- 支持批量「两字名加空格」（插入全角空格）。
- 支持正文字体、样式、字号与正文字色。
- 字号支持自动适应、每牌尽量大，以及固定磅值。
- 取色使用中文调色板（基本颜色、自定义颜色、色相 / 饱和度 / RGB）。

### 📏 桌牌规格

内置常用预设（下拉列表中不分组，可直接选）：

- V 型三角常见规格：`90*55mm`、`100*70mm`、`120*80mm`、`140*90mm`、`150*100mm`、`220*110mm`
- 平面横版：`210*70mm`、`240*100mm`、`297*100mm`
- L 型立牌常见规格：`100*80mm`、`120*90mm`
- 常用纸张：`A6`、`A5`、`A4`、`A3`、`B5`、`Letter`（也可直接输入这些名称）

也可手动输入毫米规格（约 `20～500mm`，格式如 `220*110mm`）。

**牌面模式**：

- **镜面对折**：上下两面镜像，适合 V 型三角桌牌（默认）。
- **单面**：只印一面，适合平面桌签或整页纸张（选 A4 等纸张名时默认单面）。

**桌牌方向**：横向 / 纵向（对调牌面长短边；如 A4 竖版 210×297，横版 297×210）。

支持内容边距，以及正文水平 / 垂直偏移（单位 mm，可输入三位数）。

边框可分别开关上 / 下 / 左 / 右边线，并为每边设置偏移（mm，**正数向内缩、负数向外扩**）。

### 🏷️ 题款（抬头 / 落款）

- 可分别启用抬头与落款。
- 默认位置：抬头在牌面左上，落款在牌面右下；边距随规格缩放（约 6～10mm）。未填写内容时，X / Y 会显示这套默认坐标。
- 支持内容、字体、字号、样式、文字颜色与 X / Y 坐标微调。
- 未手动改过坐标时，更换桌牌规格会按新尺寸重算默认位置。

### 🎨 牌面背景

- **纯色**：从中文调色板选择牌面底色。
- **图片**：选择 BMP / JPG / PNG，铺满单面。
- **恢复白底**：清除图片并还原白色底。

纯色与图片二选一显示；选纯色会清掉当前背景图。

### 👁️ 预览与打印

- 主界面「单牌预览」实时刷新，可用上一张 / 下一张翻看名单。
- `F8` 打开「排版预览并打印」。
- 纸上能放下几张牌就排几张；装不下的部分裁在纸边内，不缩小。
- 排版预览支持 **一页 / 两页**。两页按组翻页（1–2，然后 3）。
- 预览区可用滚轮翻页，`Ctrl + 滚轮` 缩放。
- 支持纸张尺寸（A4 / A5 / A3 / A6 / B5 / Letter）与页面方向（自动 / 纵向 / 横向）；在 **排版预览（F8）** 中设置。
- 支持边框线型、上 / 下 / 左 / 右边线及各自偏移、对折中线（仅镜面对折时可用）、线条浓度。
- 支持文字分散对齐。
- 可输出到系统打印机，或打印到 PDF。

未处理异常会写入 `crash.log`，避免静默闪退。

## ⌨️ 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `F8` | 排版预览并打印 |
| `Ctrl + P` | 预览窗口中发送到打印机 |
| `Esc` | 关闭排版预览 |
| `Ctrl + 滚轮` | 名单编辑区缩放字号；排版预览中缩放页面 |
| 滚轮 | 排版预览中翻页 |

## 🛠️ 技术架构

| 技术 | 用途 |
| --- | --- |
| Python | 应用主要开发语言 |
| PyQt6 | 桌面 GUI、预览与打印 |
| QSS | 界面样式（主色 `#0070C0`） |
| PyInstaller | Windows EXE 打包 |
| Inno Setup 7 | Windows 安装程序制作 |

项目采用模块化结构：`app` 负责启动与中文翻译，`core` 负责配置与排版数据，`render` 负责绘制打印，`ui` 负责界面，`resources` 存放只读资源。打包相关文件（`build_exe.bat`、`.spec`、`.iss`、`file_version_info.txt`）均位于项目根目录。

## 🚀 从源码运行

### 环境

- Windows
- Python 3.10+
- PyQt6

安装依赖：

```bash
pip install -r requirements.txt
```

在项目根目录启动：

```bash
python main.py
```

或：

```bash
python -m app.main
```

开发时配置写在项目根目录 `config.json`；安装版（打包 EXE）配置在 `%APPDATA%\meeting_nameplate\`。

---

## 📦 Windows EXE 打包

在项目根目录双击或运行：

```text
build_exe.bat
```

脚本会调用同目录下的 `会议桌牌打印系统.spec`，通过 PyInstaller 生成 EXE。

打包后的目录通常为：

```text
dist/
└── 会议桌牌打印系统/
    ├── 会议桌牌打印系统.exe
    ├── icon.ico
    ├── install.mark
    ├── styles/
    ├── icons/
    ├── translations/
    └── 其他运行依赖
```

任务栏图标依赖 `icon.ico` 与 Windows `AppUserModelID`（`XiaoDong.MeetingNameplate`），与安装脚本一致。

### 用户配置原则

**用户配置不应作为测试配置直接打入安装包。**

`build_exe.bat` 会尽量删除 `dist` 中的个人配置文件。程序安装后应使用用户自己的运行时配置，以避免开发环境中的测试设置被带入正式安装版本。

## 📦 Windows 安装程序

安装程序使用 **Inno Setup 7**，配置文件位于项目根目录：

```text
会议桌牌打印系统.iss
```

推荐流程：

1. 运行根目录 `build_exe.bat`。
2. 检查 `dist/会议桌牌打印系统/` 中的 EXE 能够正常运行。
3. 使用 Inno Setup 7 打开 `会议桌牌打印系统.iss`。
4. 编译安装程序。
5. 在 `dist_installer/` 取得最终安装包（`会议桌牌打印系统_Setup.exe`）。

正式安装包只包含程序运行所需文件，不应包含开发环境中的用户配置和测试数据。

## 🖥️ 使用流程

1. 启动会议桌牌打印系统。
2. 在「桌牌名单」中按行填写姓名或内容。
3. 选择正文字体、字号与桌牌规格。
4. 按需设置抬头、落款、边框，以及牌面纯色或背景图。
5. 在右侧查看单牌预览。
6. 按 `F8` 打开排版预览。可用「一页 / 两页」查看分页，滚轮翻页。
7. 确认纸张与方向后，发送到打印机或导出 PDF。
